Voice generator

Creates an AI voice file for every phonogram sound with Google Cloud Text-to-Speech, then packs them into a zip for the audio folder of your GitHub repository. Your API key is used only in this browser tab.

Listen to each sound. If one sounds off, edit its IPA and press Redo. Stop consonants such as b, t, and k can come out faint when isolated; try adding a short vowel, for example "bə".
